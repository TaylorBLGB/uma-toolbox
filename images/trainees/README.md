# Trainee portrait images

Drop portrait images here named after each trainee's name, slugified: lowercase, spaces and
punctuation turned into hyphens. E.g. `Air Groove` -> `air-groove.png`.

They're used next to the trainee search box on the Race Planner and in its suggestion dropdown, at
`images/trainees/{slug}.png`. If an image is missing it's simply hidden — no placeholder, no broken
image icon — so the site works fine with none, some, or all portraits present.

One image per trainee name (not per costume) — costume variants share the same aptitude and the same
portrait slot.
